# 上班鼓励器

看今天上班到此刻赚了多少。按一个月 21 个工作日，把月薪摊到每一秒，金额显示到小数点后四位。

在线打开：[https://oboahs.github.io/shangban-encourager/](https://oboahs.github.io/shangban-encourager/)

本地预览：

```sh
npm install
npm run dev
```

静态站（GitHub Pages）：

```sh
npm run build:pages
```

微信小程序在 `miniprogram/`。用微信开发者工具导入这个目录即可预览。正式发布要换成自己的小程序 AppID。
